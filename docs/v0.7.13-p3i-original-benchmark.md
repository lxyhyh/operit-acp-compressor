## 一、原版核心模式（bc-upstream/src/server.ts + session.ts + persist.ts）

```
宿主每轮传完整历史
  → server.prepare() → processTurn({
        messages, state: session.state,   // 内存持有 + persist 落盘
        tokenCount: session.stats.lastInputTokens,  // 上游真实 token（非 estimate）
        renderTags
     })
  → turn.state（压缩后）→ session.state = turn.state（内存）
  → persist.ts 落盘
  → 下轮 session.state 直接复用 blocks/coveredIds
```

原版要点：
1. **state 是 session 级内存持有**（sessions Map），磁盘只是备份（MAX_SESSIONS 驱逐才 flush）
2. **tokenCount = lastInputTokens**（上游真实 input_tokens，注释明示"Source of truth for tokenCount — never an estimate"）
3. **compressCreditTokens**：压缩后立即从 lastInputTokens 扣减，nudge 用真实压缩后值
4. **blockContents**：压缩时缓存原始文本（decompress 用），state 不丢原内容
5. **fingerprint 由内容指纹 id 实现**（wire message-id），非单独字段

## 二、当前 ACP 实现（operit-acp-plugin/src/acp/adapter.ts）

```
每轮宿主传完整历史
  → persistence.load(sessionKey)   // 从磁盘读 state（非内存持有）
  → processTurn({
        messages, state: workState,  // JSON 深拷贝 loaded.kernelState
        tokenCount: estimateProjectionTokens(mapping.messages, coveredIds),  // ← CJK 估算
        renderTags
     })
  → turn.state → save 到磁盘
```
