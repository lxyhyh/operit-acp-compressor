## 三、coveredIds 失效根因（核心）

- block effectiveMessageIds 使用 identity-bridge 生成的 id：
  - `host:user:content:hash`（content-fallback，稳定）
  - `host:toolcall:V${seq}_${tool}_${sigHash}`（virtual tool，**依赖易变 seq**）
- identity-bridge 的 toolSeqCounter 是**跨调用共享的可变状态**
- compress 折叠后 / 后续调用 seq 变化 → **同一 tool call 生成不同 id** → coveredIds 无法匹配
- 结果：**被压缩的工具消息仍计入 estimate** → tok 虚高（654K vs 实际投影后）
