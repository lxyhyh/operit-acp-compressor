## 6. 核心问题答案（文档第二十三节）

- Q1 静止30万来源: **DB currentWindowSize = 上次 turn completion 的 estimate（stale）**
- Q2 80万产生位置: **estimatePreparedRequestWindow → calculateInputTokens（发送前 T7）**
- Q3 谁改变: **Operit 发送路径的 calculateInputTokens（不是 ACP）**
- Q4 输入对象不同: **YES（30万=旧estimate对象，80万=当前requestHistory）**
- Q5 两个context view: **YES（stale estimate vs current estimate）**
- Q6 ACP改变规模: **NO（project raw=4045→proj=4046，仅+1 SUMMARY）**
- Q7 tools贡献: **待查（80万→90.5万 gap 含 tools/system）**
- Q8 SYSTEM贡献: **待查（system 1 turn 但可能大）**
- Q9 provider normalization: **部分（90.5万 = 80万 estimate + gap）**
- Q10 Tool Loop相关: **NO（跳变在用户发送首次就发生）**
- Q11 重复注入: **待查**
- Q12 cache/stale: **YES（30万是 stale estimate）**
- Q13 真实HTTP input: **~90.5万（token_usage_records 实证）**
- Q14 billion-context做法: **provider-anchored usage calibration**
