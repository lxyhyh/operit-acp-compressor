## 1. TOOL PATH FORENSIC — 为什么宿主看到 m05709，工具只看到 m00002

### 决定性证据（tool_params.log 实测）

```
20:45:54 [acp_status] __operit_package_chat_id=f23f6048-...  ← 活跃会话 A
20:46:28 [compress]  __operit_package_chat_id=f23f6048-...  ← 同一活跃会话 A
20:51:06 [acp_status] chatId=f23f6048-...
21:03:01 [compress]  __operit_package_chat_id=d2572685-...  ← 活跃会话 B
```

### 根因（SESSION WRONG）

**工具被调用时，宿主注入的 `__operit_package_chat_id` 是"当时 UI 活跃会话"，不是"nudge 所属会话"。**

- nudge 在 **d2572685**（本对话，45 blocks/3297 refs）生成，建议 m05709..m06088
- 但模型/宿主调用 compress 时，UI 活跃会话是 **f23f6048** 或 **d85b2fdd**（2 refs/0 blocks）
- 工具 sessionKeyFromParams 取 `__operit_package_chat_id` → 查到**错误的 session state** → ref 全解析失败

### 会话 state 矩阵（acp-state 实测）

| session | refs | blocks | 说明 |
|---|---|---|---|
| d2572685 | 3297 (m03297) | 45 | **nudge 真身**（本对话） |
| 11f990c4 | 598 | 10 | 旧会话 |
| 3f6381da | 529 | 2 | 工作区会话 |
| d85b2fdd | **2 (m00002)** | 0 | 工具曾查到的 |
| f23f6048 | **2 (m00002)** | 0 | 工具曾查到的 |

### 结论

```
HOST_NUDGE_SESSION = d2572685（45 blocks）
TOOL_ACTUAL_SESSION = f23f6048 / d85b2fdd（0 blocks）
→ HOST_SESSION_KEY ≠ TOOL_SESSION_KEY
→ SESSION WRONG（非 REF STALE）
```

## 5. PROTECTED PROJECTION DESIGN（P1/P2/P3 评估）

按文档十三节：

### P1: Temporary Protected Projection
- RAW → kernel → 发现>=hard → 生成 protected view → final request
- 优点：不持久化、简单
- 缺点：需处理 stage1/stage2/Tool Loop/cache/identity/nextHop 六处

### P2: Hard-triggered model compress round-trip
- hard → nudge → **暂停 request** → 模型 compress → 重建 → 发送
- 优点：模型主导、billion-context 语义
- 缺点：额外模型调用、延迟、token cost、失败恢复复杂

### P3: Controlled fallback projection（**推荐**）
- 主路径：hard → nudge → 模型 compress → persistent compression
- 异常路径：compress 失败/不可用 → **ProtectedProjection** → 防巨大 request
- 优点：模型主导 + 发送安全兜底，两者兼备

---

## 6. RECOMMENDATION

**选 P3**。理由：
1. 文档核心原则："模型负责长期压缩，ACP 负责 hard 时发送安全"
2. P3 是唯一同时满足"模型主导"和"当前 request 安全"的方案
3. 与现有 forced nudge 机制兼容（nudge 不变，只加 fallback）
