## 一、根因（P3-C 确认）

```
FULL path（before_finalize_prompt）
  → processTurn(V1) → turn.state=V2
  → nudge = turn.nudge(V2)  （m00125..m00240）
  → save(V2)

STAGE2/CACHE-HIT/INCREMENTAL
  → kernelState: cached.kernelState（V1，stateVersion 原样 0）
  → save(V1)  ← 后写覆盖 V2
```

每个真实 send 周期：FULL 先写 V2，STAGE2 立即写 V1 覆盖 → 磁盘永远 V1
→ nudge 给模型 m00125..m00240，但 acp_status 看到 m00001/m00002（无内容可压）。

---

## 二、修复内容

### 1. persistence.ts：stale-write monotonic guard
- `save()` 内比较 `incoming.stateVersion < current.stateVersion`
- 是 → **禁止 kernelState 回滚**，仅前向合并 hostMetadata（usage/nudge/stats 决策元数据）
- 记录日志：`[stale-write-blocked] session=... currentVersion=... incomingVersion=... source=persistence-guard`

### 2. adapter.ts FULL path：stateVersion 真正递增
- FULL processTurn 后，若 kernel 产生实质变化（refs/blocks 前进）→ `stateVersion + 1`
- 纯重投影（无变化）保持原版本，避免 cache-hit 因版本漂移永久失效

### 3. 修复后状态流
```
FULL    → kernelState=turn.state(V2), stateVersion=2 → save(V2) ✅
STAGE2  → kernelState=cached(V1), stateVersion=1 → guard 拦截 → merge(保留 V2) ✅
CACHE-HIT → 同上 → guard 拦截 ✅
INCREMENTAL → 同上 → guard 拦截 ✅
TOOL mutation → stateVersion+1 → save(V3) → 不被 project 覆盖 ✅
```
