## 2. EXECUTOR PROOF（宿主执行层 = 带冒号名）

### 2.1 AIToolHandler.getToolExecutorOrActivate（host-audit/AIToolHandler.kt:303-359）

```kotlin
fun getToolExecutorOrActivate(toolName: String): ToolExecutor? {
    var executor = availableTools[toolName]
    if (executor == null && !defaultToolsRegistered.get()) { registerDefaultTools(); executor = availableTools[toolName] }
    if (executor == null && toolName.contains(':')) {          // ← 只有带冒号才激活 package
        val packageName = toolName.substringBefore(':', missingDelimiterValue = "")
        if (packageName.isNotBlank()) {
            val packageManager = getOrCreatePackageManager()
            if (packageManager.getAvailablePackages().containsKey(packageName)) {
                packageManager.usePackage(packageName)
                executor = availableTools[toolName]
            }
        }
    }
    return executor
}
```

## 4. CONTRACT VERDICT

**PROMPT_EXECUTION_CONTRACT_BROKEN**

```
ToolPrompt 可见：  compress / absorb / decompress / search_context / acp_status（裸名）  ✅ 注入成功
AIToolHandler 可执行：acp_tools:compress / acp_tools:acp_status ...（带冒号）             ✅ 注册成功
                 ↓
裸名调用 → getToolExecutorOrActivate("compress") → 无冒号 → 不激活 package → executor=null
                 ↓
"Tool not found / unavailable"
```

**根因 = ACP 工具注入裸名，宿主执行层只认带冒号名（packageName:toolName），两者不一致。**
